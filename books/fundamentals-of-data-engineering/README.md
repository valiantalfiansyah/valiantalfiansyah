# What is this book?
This is a book by Joe Reis and Matt Housley from O`Reilly publisher.

# Why I read this book?
I found that Data Engineer profession is sometimes has a different requirement or scope between companies. Sometimes the description of DE is to automate things, sometimes it's about data scraping, or data migration. Some data engineers focus only on data architecture and SQL, the other ones focusing on building ETL pipelines using complex python code. 

This makes me confused about what is a data engineer? How can I improve and which area should I improve? Hopefully this book can answer my questions.

# How will I learn this book?
