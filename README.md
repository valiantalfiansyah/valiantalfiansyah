### Hello, I'm Valiant, a Data Engineer
I’m a data engineer with two years of experience. I started out in GIS, and over time I found myself working with spatial datasets that had outgrown desktop GIS tools capabilities. That pushed me toward the engineering side of data, which is where I’ve focused since.

Today I work with cloud data platforms such as Databricks and Snowflake, orchestrate pipelines with Airflow, and write Python and SQL. For storage I’ve used Azure Blob Storage and Google Cloud Storage, and for relational databases PostgreSQL and Microsoft SQL Server.

I enjoy designing data architecture around what the business actually needs, and I try to build with solid engineering practices such as modularity, unit-tested code, layered architecture, and CI/CD through GitHub Actions or Azure DevOps. 

Feel free to reach out if you’d like to talk about data engineering or GIS work. I’m always happy to connect and exchange ideas 😆
